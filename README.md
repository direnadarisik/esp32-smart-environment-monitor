# ESP32 Smart Environment Monitor

An ESP32-based environmental monitoring system using a DHT22 sensor and OLED display.

## Features

- Temperature monitoring
- Humidity monitoring
- OLED display
- Wi-Fi connectivity
- Temperature alerts

## Components

- ESP32
- DHT22 temperature and humidity sensor
- OLED display

## Libraries

- DHT sensor library
- Adafruit GFX Library
- Adafruit SSD1306

## Project Status

The code was successfully compiled and verified in Arduino IDE.
